# 🚀 Formation Intensive Java/Spring/React
## Débutant → Junior Opérationnel en 4 Semaines

**Bienvenue dans ce parcours intensif !** Vous avez 4 semaines pour construire les fondations solides d'un développeur Full Stack Junior capable de contribuer opérationnellement sur des projets réels.

---

## 📋 **Table des Matières**

| Semaine | Thème | Durée | Niveau |
|---------|-------|-------|--------|
| [🔗 Semaine 1](#semaine-1--fondations-java) | Fondations Java (POO, Collections, Mémoire, Git) | 5 jours | ⭐ |
| [🔗 Semaine 2](#semaine-2--backend-spring-boot) | Backend Spring Boot (API REST, Architecture, DI) | 5 jours | ⭐⭐ |
| [🔗 Semaine 3](#semaine-3--frontend-react) | Frontend React (Composants, State, Hooks) | 5 jours | ⭐⭐ |

---

## 🎯 **Objectif Global**

À l'issue de cette formation, vous serez capable de :
- ✅ Écrire du code Java orienté objet **maintenable et testable**
- ✅ Construire une API REST robuste avec **Spring Boot**
- ✅ Créer une interface **React moderne et interactive**
- ✅ Intégrer front et back dans une **architecture professionnelle**
- ✅ **Déboguer et déployer** une application complète
- ✅ Défendre vos choix **techniques en entretien**

---

## 📚 **Structure du Parcours**

### [Semaine 1 → Fondations Java](./semaines/semaine-1.md)
Les briques élémentaires sans lesquelles le reste s'écroule.
- Programmation Orientée Objet
- Collections et structures de données
- Gestion de la mémoire et garbage collection
- Contrôle de version avec Git

### [Semaine 2 → Backend Spring Boot](./semaines/semaine-2.md)
Construire un API REST professionnel avec les patterns de l'industrie.
- Création d'une application Spring Boot de zéro
- Construction d'endpoints REST robustes
- Injection de dépendances et architecture en couches
- Gestion des erreurs et logging

### [Semaine 3 → Frontend React](./semaines/semaine-3.md)
Concevoir une interface utilisateur moderne et performante.
- Architecture des composants React
- Gestion du state et des props
- Hooks et cycle de vie
- Communication avec une API

### [Semaine 4 → Intégration Full Stack](./semaines/semaine-4.md)
Assembler tout en une application professionnelle et testée.
- Intégration front/back
- Tests d'intégration
- Déploiement et performance
- Préparation aux tests techniques d'embauche

---

## 🛠️ **Prérequis**

- Java 11+ installé
- Node.js 16+ et npm
- Git installé et configuré
- Un terminal/IDE (VS Code, IntelliJ recommandé)
- **Mentalité**: patience, curiosité, rigueur
