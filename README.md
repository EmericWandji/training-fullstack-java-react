## 🎯 Compétences Cibles (Votre futur profil)

À la fin de ce sprint de 20 jours, votre cerveau aura automatisé les circuits neuronaux nécessaires pour :
* **Concevoir** des architectures Java robustes, découplées et hautement testables.
* **Forger** des API REST industrielles avec Spring Boot capables de traiter des flux réels.
* **Sculpter** des interfaces utilisateurs dynamiques, fluides et réactives avec React.
* **Fusionner** l'écosystème Front et Back à travers des configurations sécurisées.
* **Défendre** vos décisions techniques devant un jury de recrutement avec l'autorité d'un praticien.

---

## 🛠️ Configuration du Laboratoire (Prérequis)

Avant d'activer le premier circuit, assurez-vous d'avoir installé vos outils de production :
* **JDK 11+** (Le moteur d'exécution)
* **Node.js 16+ & npm** (L'écosystème JavaScript)
* **Git** (Votre machine à remonter le temps pour le code)
* **IDE** (IntelliJ IDEA ou VS Code configurés)
